Frequently Asked Questions

How is my data encrypted?

We use envelope encryption. Every file generates a unique AES-256-GCM data key. Chunks are encrypted locally before being distributed to storage nodes.

What happens if a node goes offline?

We enforce a replication factor of 3. If a node fails, your file is served from another healthy replica, and a background worker duplicates it to a new node to maintain redundancy.

How long do Share Links last?

You can define a maximum download limit or an expiration date when generating the link. You can also revoke them manually at any time.
